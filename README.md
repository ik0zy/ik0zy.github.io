# ik0zy.github.io

Personal portfolio of Mohammad Saidul Islam — **v5 "FIELD SURVEY"**: the portfolio
as a topographic survey sheet, drawn in ink on paper.

- **Plate I · Survey Plate** — an interactive SVG topographic map. Six numbered,
  pulsing markers plot the real career highlights (Kaggle Expert summit, the IEEE
  paper's confluence, twin Breakthrough first places, UIU-Calendar monument, the
  club leadership station, the degree datum). Click any marker for a surveyor's
  detail card; keyboard accessible.
- **Peaks & Elevations** — achievements rendered as summits with a percentile
  elevation profile (40/1564).
- **The Watercourse** — the ICCIT '25 publication as the one river on the map.
- **Monuments / Benchmark Stones** — project and CV history in survey notation.
- **Case of Instruments** — skills with field-wear meters.
- **Survey Office** — contact.

## Stack

- Plain HTML + CSS + vanilla JS. No frameworks, no build step, no external requests.
- Fonts self-hosted: Fraunces (instance of Google's OFL variable font, instanced
  locally), IBM Plex Mono 400/500/600. Archivo retained for system fallback.
- The map is hand-authored inline SVG: graticule generated by JS, contours and
  river drawn as bezier paths. No map libraries.
- Animations respect `prefers-reduced-motion`.

## Editing

Content lives in `index.html`; marker data lives at the top of `js/main.js`
(`MARKERS`). Preview locally:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

Commit and push — GitHub Pages redeploys automatically (branch: `master`, root).
